# 🍕 Make Your Pizza

A simple **Windows Forms (C# / .NET Framework)** desktop application that lets the user build their own pizza by choosing the size, crust type, toppings, and where to eat. The order summary and the total price update live as the user changes any option, and the order is confirmed on a separate checkout screen.

---

## ✨ Features

- Welcome screen with **Get Started** and **Exit** buttons.
- Choose the pizza **size**: Small / Medium / Large.
- Choose the **crust type**: Thin Crust / Thick Crust.
- Choose any combination of **toppings**: Extra Cheese, Onion, Mushrooms, Olives, Tomatoes, Green Peppers.
- Choose **where to eat**: Eat In / Take Out.
- **Live Order Summary** panel that updates instantly with every change.
- **Total price calculated automatically** (size + crust + toppings).
- **Reset** button to return all options to their defaults.
- **Checkout screen** showing the full order details with a confirmation dialog before placing the order.
- Custom dark themed UI with a background image and custom fonts.

## ⚙️ How It Works

### 1. Main Form – `Form1`
- `Get Started` creates a new `Order` form and shows it.
- `Exit` closes the main form (and the application).

### 2. Order Form – `Order`

Prices are stored in the **`Tag`** property of each `RadioButton` / `CheckBox`, and the code reads them with `Convert.ToSingle(control.Tag)`. This means you can change any price from the Visual Studio designer without touching the code.

Main methods:

| Method | Purpose |
|--------|---------|
| `GetSelecedSizePrice()` | Returns the price of the selected size. |
| `GetSelectedCrustTypePrice()` | Returns the price of the selected crust. |
| `GetToppingPrice()` | Sums the prices of all checked toppings. |
| `ClaculateTotalPrice()` | `Size price + Crust price + Toppings price`. |
| `UpdateTotalPrice()` | Writes the total into the price label (`$`). |
| `UpdateSize()` | Updates the price and returns the size text. |
| `UpdateCrust()` | Updates the price and returns the crust text. |
| `UpdateTopping()` | Updates the price and builds the toppings text (`No Toppings.` if none selected). |
| `UpdateWhereToEatLabel()` | Returns `Eat In` or `Take Out`. |
| `Reset()` | Restores the defaults: Small, Thin Crust, Eat In, no toppings. |

Every `CheckedChanged` event of the radio buttons and checkboxes refreshes the corresponding label in the **Order Summary** panel.

When **Order Pizza** is clicked, a `Checkout` form is opened as a dialog (`ShowDialog()`) and the order data is passed to it. After the dialog closes, the form is reset.

### 3. Checkout Form – `Checkout`

The constructor receives the order data:

```csharp
public Checkout(string PizzaSize, string PizzaTopping, string PizzaCrustType, string WhereToEat, float Price)
```

and shows it in the labels. On **Check Out**:
1. A `MessageBox` asks **"Are You Sure ?"** (OK / Cancel).
2. If the user presses OK, a success message **"Order Placed Successfully"** is shown and the form closes.

**Cancel** simply closes the checkout screen.

## 🚀 Getting Started

### Prerequisites
- Windows OS
- [Visual Studio](https://visualstudio.microsoft.com/) with the **.NET desktop development** workload

### Run the project
1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/<your-repo-name>.git
   ```
2. Open the `.sln` file with Visual Studio.
3. Press **F5** (or click **Start**) to build and run.
